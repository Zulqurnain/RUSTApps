# RUSTApps

A series of Rust-based applications built for practice and learning systems programming.

## Apps

| App | Description | Status |
|-----|-------------|--------|
| hello_world | Basic Rust program | ✅ |
| calculator | CLI calculator | 🔄 |
| file_reader | File I/O operations | 🔄 |
| http_client | HTTP requests with reqwest | 🔄 |

## Getting Started

```bash
git clone https://github.com/Zulqurnain/RUSTApps.git
cd RUSTApps

# Run any app
cd hello_world
cargo run
cargo test
```

## Prerequisites

- [Rust](https://rustup.rs/) (latest stable)
- Cargo (included with Rust)

## Learning Resources

- [The Rust Book](https://doc.rust-lang.org/book/)
